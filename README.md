# StringLibrary (ЛР4)

Лабораторная работа №4. Библиотека классов «Работа со строками» + модульные тесты.

## Структура
- StringLibrary — интерфейс IStringService, реализация StringService, исключение StringException
- StringLibrary.Tests — тесты xUnit

## Сборка и запуск
1. Открыть StringSolution.sln в Visual Studio 2022.
2. Сборка: Ctrl+Shift+B.
3. Тесты: Ctrl+R, A.
